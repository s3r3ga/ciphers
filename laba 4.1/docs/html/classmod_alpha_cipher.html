Класс для шифрования и дешифрования текста методом Гронсвельда

Класс реализует алгоритм шифрования Гронсвельда с поддержкой русского алфавита. Шифрование осуществляется путем сдвига букв на величину, определяемую ключом.

Алгоритм дешифрования является обратным к алгоритму шифрования:

  1. Преобразование текста в верхний регистр
  2. Проверка валидности символов
  3. Преобразование текста в числовой вид
  4. Обратный сдвиг на величину ключа
